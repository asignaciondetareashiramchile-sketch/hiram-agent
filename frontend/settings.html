📧 Configuración SMTP (Correos Electrónicos)

Configura los datos de tu servidor de correo para que el sistema envíe notificaciones a las áreas.

🔌 Verificando estado SMTP...
Ej: smtp.gmail.com, smtp.office365.com, smtp.sendgrid.net
587 (TLS) o 465 (SSL)
Para Gmail usa una App Password
Dirección que aparecerá como remitente

☁️ Microsoft Graph API (Office 365)

Alternativa a SMTP para enviar correos desde Office 365. Requiere registro de app en Azure AD.

🔌 Verificando estado Graph API...
ID del inquilino de Azure AD (se encuentra en Azure Portal → Azure Active Directory → Propiedades)
ID de la aplicación registrada en Azure AD
Secret generado en Azure AD → App registrations → Certificates & secrets
Cuenta con licencia Exchange Online que enviará los correos

🌐 URL Pública (Botones de Email)

Configura la URL pública para que los botones "Gestionando" y "Realizado" en los correos funcionen desde cualquier cliente de email.

🔌 Verificando túnel...
Usa localhost.run: ssh -R 80:localhost:8080 nokey@localhost.run — la URL se muestra al conectar (ej: https://xxxx.lhr.life)
